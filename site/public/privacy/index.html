Privacy policy

Effective 2026-09-06. Operator: the maintainer of github.com/ken-jo/agent-connector.

This website (agent-connector.ai)

  • Static pages served by GitHub Pages behind Cloudflare. Both providers log requests (IP address, user agent, requested path, time) to operate the service; the operator reads Cloudflare's aggregate analytics of those logs.
  • No accounts, no forms, no cookies set by the site, and no third-party analytics or advertising scripts.

The agent-connector SDK and CLI

  • The software runs on your machine. It does not send data to the operator.
  • Optional per-tool token telemetry is stored locally and holds aggregate counts only, never tool arguments or results. Details and the opt-out: /docs/dev/privacy.

Google OAuth client

  • The operator registers a Google OAuth client named after this project to read the operator's own Google Search Console data for agent-connector.ai (scope webmasters.readonly).
  • Tokens are stored only on the operator's machine. No other person's Google data is requested, accessed, shared, or stored, and the client is not offered to the public.
